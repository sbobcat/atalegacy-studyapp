# atalegacy-studyapp



## checking and testing build

1. Run project checks

```
cd C:\Code\pers\atalegacy-studyapp
npm run ingest
npm run lint
npm run typecheck
npm run build
```

Run `npm ci` if dependencies are not installed.
2. Open the app

```
npm run dev
```

3. Run the production version

```
npm run preview
```

4. Check the current automated test gap

```
npm test
```
